# usvc-frontend coding rules

1. **Proxy only.** Browser → `fetch("/api/backend…")` via `lib/api.ts` / `lib/staff-client.ts`. Upstream = server-only `API_URL` in `app/api/backend/[...path]/route.ts` (streams body with `duplex:half`, forwards `content-type` + `authorization` only, passes `content-disposition` for downloads, `no-store`, 502 JSON on failure). No direct backend URLs, no `NEXT_PUBLIC_*` API vars, no server secrets in client code.
2. **Stripe Elements only.** Never build raw card number / CVV / expiry inputs. Checkout uses `@stripe/react-stripe-js` `PaymentElement` tabs (`useCheckout`: validate → confirm → `onPaid({sessionId})` → `POST /api/backend/checkout/verify` → `/order/confirmation?session_id=`). Appearance themed to USVC (Times, red/navy).
3. **SSN/card hygiene.** Form must not send SSN to analytics, logs, URLs, or browser storage. `sessionStorage` draft excludes SSN/card. Review shows generic "Card provided (kept private)", never digits. Notes warn (not block) on SSN/card-like content.
4. **Totals are display-only.** Backend recalculates; call `verify-before-payment` before `createOrder`. Mismatch → show server error, never override.
5. **Tokens are locked.** Public: Times stack, Navy/Red/white/soft-gray (`app/globals.css`). Staff: own `staff.css` + Inter, never on public pages. Red buttons keep red (opacity/outlines for feedback, no dark-red/blue alternates). Status pills always have text, never color alone.
6. **Form conventions.** Config-driven (`lib/form-config.ts` + `resolveFormConfig`); copies 1–20; explicit home→shipping/billing copy radios; live review blocks with Edit-scroll; `react-international-phone` (US default, E.164); confirm-email paste-block; server errors scroll + focus + `data-invalid` red highlight + inline tinted messages + clickable error summary (`county` owns its lifecycle for the blocked-county banner).
7. **Staff conventions.** SessionStorage JWTs, `staffFetch` with one refresh retry; `useRequireStaffAuth` + 30-min inactivity sign-out; `ConfirmModal` for destructive actions (never `window.confirm`); lucide icons always paired with text; tables stack to cards <760px; no analytics on staff.
8. **Quality gates.** `npm run format`, `npm run format:check`, `npm run lint`, `npm run build`. Pre-commit: lint-staged + `tsc --noEmit`. ESLint 9; TS gate is `tsc`.
9. **Git.** `feat/<name>` from `develop` → PR to `develop`. Never commit to `main`/`develop`.
