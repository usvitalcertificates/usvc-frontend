## Verification and maintenance

- Run `npm test`, `npm run format:check`, `npm run lint`, `npm run build`, then `npm run test:seo`.
- `test:seo` starts and stops a local production server with analytics disabled. It does not submit applications, send emails, make payments, or change Google settings.
- Update this tracker and `docs/status.md` with actual checks and Git/deployment state. Do not mark work deployed based on a push, PR or local build alone.
- Keep sitemap dates stable between actual changes; distinguish page modification dates from official-source verification dates. llms.txt links the maintained public pages rather than duplicating volatile facts.
- Follow-up Search Console checks require an actual recrawl and comparable finalized windows. Indexing requests and metadata changes do not guarantee inclusion or ranking improvements.
