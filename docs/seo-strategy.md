# USVC SEO strategy

## Goal and guardrails

Primary outcome: verified paid orders and organic revenue. USVC is an independent document assistance service, not a government agency. Public content never includes customer data, unsupported legal or eligibility claims, fabricated endorsements, paid links, or copied agency text.

## Index policy

Canonical host: `https://usvitalcertificates.org`. Index public marketing pages, state landing pages, canonical `/state/{state}/order/{certificate}` application pages, and source-backed guides. Do not index staff, `flow.*`, `/api`, checkout, confirmation, tracking, legacy duplicate application routes, previews, or staging. `robots.txt` permits public crawling and references the sitemap.

## Technical inventory

- `robots.txt` and `sitemap.xml` are generated by Next.js.
- Root Organization JSON-LD uses only USVC's public name, URL, logo, and support email.
- FAQ remains visible-content FAQPage JSON-LD; guides use Article and BreadcrumbList JSON-LD.
- No `llms.txt`, AI-only markup, review schema, LocalBusiness schema, or unsupported government-affiliation claims.

## Keyword and page map

| Intent                              | Destination                          | Primary conversion |
| ----------------------------------- | ------------------------------------ | ------------------ |
| General certificate help            | Home, Certificates, FAQ              | Find a state       |
| State birth-certificate information | `/guides/{state}/birth-certificate`  | Start request      |
| State certificate application       | `/state/{state}/order/{certificate}` | Application start  |
| Existing customer help              | Contact, Track Order (noindex)       | Support / tracking |

## Guide pilot

States: California, Texas, Florida, New York, Pennsylvania, Illinois, Ohio, Georgia, North Carolina, Michigan. Every guide links to a public official issuing-agency resource, uses an original summary, displays a source-checked date, and tells readers the agency controls requirements. Publish no state-specific fee, eligibility, or timing claim unless sourced and reviewed.

## Measurement and decisions

After deployment: verify Search Console and Bing Webmaster Tools, submit the sitemap, and record baseline indexed URLs, impressions, clicks, Core Web Vitals, organic application starts, verified paid orders, revenue, and organic conversion rate. Review at 8 and 12 weeks. Expand only when pilot guides are indexed, attract qualified impressions, and contribute to a verified paid order without accuracy/support issues.
